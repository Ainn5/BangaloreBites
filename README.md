# Bengaluru Bites

A public restaurant discovery directory for Bengaluru, maintained by Ainn.

## Public website

https://ainn5.github.io/BangaloreBites/

## Deployment

The site is published to GitHub Pages by the GitHub Actions workflow at `.github/workflows/pages.yml`. Every push to `main` triggers deployment.

## Analytics

The page is configured to use GoatCounter at https://ain.goatcounter.com/.
